# Standard-Sec

**Standard security orchestration, powered by standard security schemas.**

An edge-native, pluggable governance control plane built with TypeScript and Cloudflare.  
Unify technical scanners (`SARIF`, `OCSF`, `CycloneDX`) and human attestations into continuous compliance loops mapped to `NIST CSF 2.0`, `CIS Controls v8.1`, and `OSCAL`.
